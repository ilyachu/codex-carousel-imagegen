# Онбординг пользователя

## Для кого это

Для автора, редактора, маркетолога или эксперта, который хочет быстро собрать карусель из текста без ручной сборки слайдов в Figma или Canva.

## Что нужно перед стартом

- установлен Codex или Claude Code
- доступен локальный `npm`
- установлен skill `codex-carousel-imagegen`
- для картинок в Claude Code ключ fal.ai не нужно класть в репозиторий: агент сам спросит его и сохранит в `~/.config/fal/key`

Claude Code видит скилл из `.claude/skills/codex-carousel-imagegen` в этом репозитории и из `~/.claude/skills/codex-carousel-imagegen` после `./install.sh`. Картинки в Claude Code собирает `scripts/fal_nano_banana.py` моделью `fal-ai/nano-banana`. Если `~/.config/fal/key` и `FAL_KEY` пусты, агент останавливается, просит ключ и записывает его в этот файл с правами `600`. В Codex по-прежнему используется встроенная генерация изображений.

## Минимальный сценарий

1. Открой проект:

```bash
cd /Users/ilyachumachenkov/Documents/karuseli/carousel-skill-lab
```

2. Запусти Codex:

```bash
codex
```

3. Вызови skill:

```text
Use $codex-carousel-imagegen.
```

4. Перед стартом можешь зафиксировать режим генерации и стиль:

```bash
npm run kickoff
```

Либо сразу без интерактива:

```bash
npm run kickoff -- --non-interactive --mode hybrid --platform telegram --tone бодро --background "журнальный с лёгкой плёнкой" --text-style "крупный заголовок"
```

После этого используй готовый файл:

```bash
carousel-output/SESSION_PROMPT.md
```

5. Дай исходник:
- тему
- текст поста
- статью
- тезисы

6. Ответь на стартовые вопросы. В нормальном сценарии skill должен спросить:

- как генерируем: гибридно, целиком через Image Gen или только рендером
- для какой площадки и какой нужен тон
- какой фон и настроение нужны
- какой нужен текстовый стиль: крупнее, плотнее, строже или мягче

7. Дождись, пока Codex соберёт структуру и, если нужно, визуалы через встроенную генерацию изображений Codex.

8. Собери итоговые PNG:

```bash
npm run export
```

9. Проверь результат в:

```bash
carousel-output/png/
```

## Как вносить правки

Напиши в Codex обычным языком, что нужно поменять.

Примеры:

- Сделай стиль строже и спокойнее.
- Замени палитру на более светлую.
- Сделай заголовки короче.
- Убери лишнюю декоративность.
- Переделай только 1 и 7 слайд.
- Сохрани фактуру, но поменяй шрифтовую пару.

## Что меняется под капотом

- логика и подача: `brief.md`, `slides.md`
- стиль: `style-lock.md`
- данные для рендера: `carousel-data.json`
- внешний вид шаблона: `carousel-renderer/src/styles.css`

## Если export не сработал

Попробуй:

```bash
npm install
npx playwright install chromium
npm run export
```
