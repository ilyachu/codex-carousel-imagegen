# Demo Prompt

Use `$codex-carousel-imagegen`.

Сделай карусель 1080x1350 на 7 слайдов для Telegram и Instagram по теме:

> Почему бизнесу стоит начинать внедрение ИИ не с выбора модели, а с описания бизнес-процессов

Требования:

- русский язык
- короткие тексты
- без длинных тире
- без выдуманных фактов
- `$imagegen` использовать только для фонов и визуальных метафор
- финальный текст рендерить через HTML/CSS
- экспортировать PNG
- сохранить все промты и результат в `carousel-output/`

- как генерируем: hybrid / imagegen-only / render-only

- какой нужен текстовый стиль
